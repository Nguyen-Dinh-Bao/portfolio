# ContactKinz

A minimalist personal website for GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — minimalist white/dark theme
- `script.js` — interactions, forms, local demo account system

## Important
This version is a **front-end prototype** for GitHub Pages. Account data, passwords, feedback, and recommendations are stored in the browser's `localStorage`. This is not suitable for real user accounts or sensitive information.

For a real production account system, the next version should use a backend/authentication service and a database.
